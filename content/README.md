# 포트폴리오 내용 고치는 법

이 사이트는 `content/` 폴더의 글 파일(.yml, .md)을 읽어서 화면을 그립니다.
문장, 경력, 작품을 바꿀 때는 이 폴더의 파일만 고치면 되고, `index.html` 은 건드리지 않아도 됩니다.
예외 하나: 첫 화면 맨 위 명함(사진, 이름, 경력 두 줄)은 `profile.yml` 의 `name` / `name_en` / `photo` / `card` 로 그려지는데, 불러오는 동안 먼저 보이는 같은 명함은 내용 파일보다 먼저 떠야 해서 `index.html` 의 `pf-splash` 블록에 직접 적혀 있습니다. 이름이나 회사가 바뀌면 거기도 똑같이 고치세요.

## 미리 보기

1. VS Code 에 **Live Server** 확장을 설치합니다.
2. `ProfilePage` 폴더를 열고, `index.html` 을 연 상태에서 오른쪽 아래 **Go Live** 를 누릅니다.
3. 내용 파일을 저장하면 브라우저가 알아서 새로 고쳐집니다.

`index.html` 을 더블클릭해서 바로 열면(주소가 `file://` 로 시작) 브라우저 보안 정책 때문에
내용 파일을 읽지 못하고 안내문만 나옵니다. 꼭 Live Server 같은 로컬 서버로 여세요.

## 파일 지도

| 파일 | 화면에서 맡는 곳 |
| --- | --- |
| `site.yml` | 섹션 순서, 메뉴 이름, 배경색 |
| `profile.yml` | 첫 화면: 명함(이름, 사진, 경력 `card`), 한 줄 소개, 요약, 칸(facts)과 로고, 링크, 연락처 |
| `skills.yml` | 업무 숙련도 표와 사용 도구 |
| `career/*.md` | 회사 경력 하나. 앞부분은 요약, 본문은 '경력 상세' 펼침 목록 |
| `impact.yml` | 성과 지표 그래프 |
| `spatial-audio.yml` | 공간음향 차폐 데모: 설명, 와이즈 공간음향 대신 직접 계산한 이유(`realtime`), 부하를 줄인 방법(`optimizations`), 층별 3D 배치도(`layers`, 적는 법은 파일 맨 위 주석) |
| `projects.yml` | 학생 시절 작품 |
| `activities.yml` | 학력, 수상, 교육, 동아리 |

파일마다 맨 위 주석(`#` 로 시작하는 줄)에 항목별 설명이 있습니다.

## 자주 하는 일

### 경력 기간 (자동 계산)

글 안에 아래 표기를 쓰면 오늘 날짜로 계산한 기간으로 바뀝니다. 해가 바뀌어도 고칠 필요가 없습니다.

| 표기 | 바뀌는 값 (2026년 10월 기준) |
| --- | --- |
| `{total}` | 모든 경력 기간의 합: 4년 11개월 |
| `{prasia}` | `site.yml` 에서 id 가 prasia 인 경력: 3년 11개월 |
| `{like-or-die}` | id 가 like-or-die 인 경력: 1년 |

- 기간은 경력 파일의 `period` 로 계산합니다. `2021.11 ~ 2025.09` 는 시작 달과 끝 달을 모두 세고,
  `2025.10 ~ 현재` 는 지난달까지 셉니다.
- `.yml` 파일과 `.md` 파일 앞부분(`---` 사이)에서 쓸 수 있습니다. `.md` 본문(경력 상세)은 그대로 둡니다.
- 값이 `{` 로 시작하면 따옴표로 감쌉니다. 예) `meta: '{total} (2021.11 ~ 현재)'`
- 지금 쓰는 곳: `profile.yml` 의 brief, `skills.yml` 의 lead 와 도구 목록, `career/nc-like-or-die.md` 의 duration.

### 회사(경력) 추가

1. `career/nexon-prasia.md` 를 복사해 `career/새회사.md` 로 저장하고 `---` 사이 값을 고칩니다.
2. `site.yml` 의 `sections` 에 블록을 하나 더 씁니다.

   ```yaml
     - id: new-game
       nav: New Game
       type: career
       source: career/새회사.md
       style: alt
   ```

3. 대표 이미지는 `images/` 에 넣고 `image`, `image_alt` 에 적습니다. 가로 16:9 가 잘 맞습니다.
4. 퇴사하면 `period` 의 `현재` 를 `2027.03` 처럼 끝 달로 바꿉니다.
   `profile.yml` 의 한 줄 소개(brief)가 "지금은 ... 일하고 있는" 이라고 되어 있으니 함께 고치세요.

### 경력 상세 항목 쓰기

`.md` 파일 본문은 `##` 제목 하나가 항목 하나입니다.

```markdown
## 리플레이 시스템 {#replay}

첫 문단은 접혀 있어도 늘 보이는 요약입니다.

- 이 아래부터는 제목을 눌러 펼쳐야 보입니다.
- 이미지는 ![설명](images/work/파일.png) 처럼 넣습니다.
```

- `{#replay}` 는 항목 주소입니다. `index.html#like-or-die--replay` 로 바로 열 수 있고,
  숙련도 표의 버튼도 이 이름으로 찾아옵니다. 영문 소문자, 숫자, `-` 만 씁니다.
- 제목 끝에 `(R&D)` 를 붙이면 제목 옆에 R&D 표시가 붙습니다.
- 첫 문단 없이 바로 목록으로 시작하면 항목 전체가 접힙니다.
  첫 문단만 있고 나머지가 없으면 펼치는 버튼 없이 그대로 보입니다.
- Chrome, Edge 에서는 브라우저 찾기(Ctrl+F)가 접힌 내용도 찾아서 펼쳐 줍니다.

펼친 안쪽에서는 아래 표기도 쓸 수 있습니다.

```markdown
### 작은 제목

| 지표 | 전 | 후 | 변화 |
| --- | ---: | ---: | ---: |
| VFX 폴더 로드 | 18.4초 | **4.5초** | −76% |

![대체 글](images/work/파일.png "이미지 아래에 나오는 설명")
![대체 글](images/work/파일.png#slide "설명")
![대체 글](images/work/파일.png#toast "설명")
![대체 글](images/work/파일.png#toast=images/창.png "설명")
```

- `###` 는 항목 안의 작은 제목입니다.
- 표는 `---:` 로 쓴 칸이 오른쪽 정렬됩니다. 휴대폰에서는 글자를 줄여 화면 폭 안에 넣으니, 칸은 네 개 정도까지가 알맞습니다.
- 이미지 주소 뒤의 `"..."` 는 이미지 아래 작은 설명이 됩니다.
  주소 끝에 `#slide` 를 붙이면 화면에 들어올 때 왼쪽에서 오른쪽으로 미끄러져 들어옵니다.
  `#toast` 를 붙이면 모니터 모양 상자의 오른쪽 아래 자리로 오른쪽 밖에서 왼쪽으로 알림처럼 들어오고, 아래에 다시 재생 버튼이 붙습니다.
  `#toast=images/창.png` 처럼 `=` 뒤에 이미지를 적으면 알림을 눌렀을 때 그 이미지가 게임 창처럼 앞으로 나옵니다.

### 숙련도 표 쓰기

'숙련 내용' 칸은 두 줄입니다. `summary` 에 한 문장으로 짧게, `detail` 에 쓴 기술과 한 일을 자세히 적습니다.

오른쪽 버튼은 `skills.yml` 의 `projects` 에 `ref: 섹션 id#항목 id` 를 적어 연결합니다. 예) `ref: like-or-die#replay`
없는 항목을 가리키면 버튼이 이동하지 않는 글자로 바뀌고, 브라우저 개발자 도구 콘솔에 경고가 남습니다.

### 성과 지표 추가

`impact.yml` 의 `cases` 에 묶음을 추가하고 `metrics` 에 지표를 적습니다.
`before` / `after` 는 숫자만, 단위는 `unit` 에 씁니다. 그래프는 낮을수록 좋은 지표를 기준으로 그립니다.
빨간 막대가 개선 전(100%)이고, 그 위에 겹친 초록 막대가 개선 후입니다. 남은 빨간 부분이 줄어든 만큼입니다.

### 작품, 활동 추가

`projects.yml` 의 `items`, `activities.yml` 의 `groups` 에서 기존 항목을 복사해 고칩니다.
`activities.yml` 항목에 `highlight: 게임` 처럼 적으면 그 항목 글자가 굵어지고 옆에 '게임' 표시가 붙습니다.
영상은 Google Drive 공유 링크 `drive.google.com/file/d/여기/view` 의 '여기' 부분만 `video` 에 적습니다.
작품 이미지는 정사각형(지금은 500×500)으로 넣습니다. 이미지 칸이 정사각형이라 그대로 다 보입니다.

### 섹션 빼기, 순서 바꾸기

`site.yml` 에서 블록을 지우거나 통째로 옮깁니다. 메뉴도 같이 바뀝니다.

## 쓸 때 주의할 점

**YAML (.yml 파일과 .md 앞부분)**

- 들여쓰기는 스페이스로 맞춥니다. 탭이 섞이면 오류가 납니다.
- 값이 `[` `{` `*` `&` `!` `|` `>` `'` `"` `%` `@` `` ` `` 중 하나로 시작하면,
  따옴표로 감싸거나 `>-` 를 붙이고 다음 줄에 들여 씁니다.
- 문장 안에 `: ` (콜론 + 공백) 이나 ` #` (공백 + 샵) 이 있으면 같은 방법으로 감쌉니다.
- 숫자도 적은 그대로 나옵니다. `19.0`, `2020.10` 이 `19`, `2020.1` 로 바뀌지 않습니다.
- 잘못 쓰면 그 섹션 자리에 파일 이름과 몇 번째 줄인지 적힌 오류 상자가 나오고, 나머지 섹션은 그대로 보입니다.
- 여러 줄 값은 `|-` 와 `>-` 가 다릅니다. `|-` 는 엔터가 화면에서도 줄바꿈이고 빈 줄은 문단을 나눕니다.
  `>-` 는 여러 줄을 한 문단으로 이어 붙입니다. 파일에서만 줄을 나눠 쓰고 싶을 때 씁니다.

**줄바꿈**

- `.md` 본문과 `|-` 값에서는 엔터 한 번이 화면에서도 줄바꿈입니다. 빈 줄을 넣으면 문단이 나뉩니다.
- 앞 문장을 이어받는 문장("그래서", "~해 보니")은 엔터 없이 한 줄로 이어 씁니다.
  다른 이야기로 넘어갈 때만 엔터를 칩니다.

**글 표기 (Markdown)**

- `**굵게**`, `[링크 글자](주소)`, `` `코드` ``, `- 목록` 을 쓸 수 있습니다.
- `` `코드` `` 안의 긴 이름은 `::`, `.`, `(` 뒤에서 줄이 바뀝니다. 휴대폰에서도 글자 중간이 잘리지 않습니다.
- 취소선은 물결 두 개 `~~글자~~` 입니다. `2021.11 ~ 2025.09` 처럼 물결 하나는 그대로 나옵니다.
- `http` 로 시작하는 링크와 `.pdf` 링크는 새 탭에서 열립니다.
- `*` 를 글자 그대로 쓰려면 `A\*` 처럼 앞에 `\` 를 붙입니다.

## 올리기 (GitHub Pages)

빌드 과정 없이 저장소에 push 하면 그대로 올라갑니다.
`.nojekyll` 은 GitHub Pages 의 Jekyll 변환을 끄는 빈 파일이라 지우면 안 됩니다.
